## 接入模式一览

不同场景下，rtc-agent 的典型接入方式：

| 宿主技术栈 | 接入方式 | 适用场景 | 代表案例 |
| --- | --- | --- | --- |
| Svelte / 静态站点 | `<rtc-agent>` 标签直接挂载 | 单页应用、轻量集成 | Mermaid Live Editor |
| React / Vue / 任意框架 | Web Component + `window.xxx` API | 复杂业务应用、多模块 | Peep |
| 框架无关 | npm 包 + 声明式配置 | 希望深度定制 | （欢迎投稿） |

## 通用接入步骤

无论哪种模式，核心流程都只有三步：

1. **暴露宿主 API 到 `window`** —— 让 Agent 能读写你的业务状态
2. **声明 Agent 身份与工具** —— 通过 `agentConfig` 描述 persona 和 functions
3. **挂载 `<rtc-agent>` 组件** —— 配置 `app-label` / `scenarios-url` / `server-url`

详细教程见 [Getting Started →](/docs/getting-started/)
