## Integration Patterns

Typical integration patterns across different scenarios:

| Loading Method | Host Stack | Window Mode | Use Case | Example |
| --- | --- | --- | --- | --- |
| **CDN** | Astro / static sites | Floating | Docs, blogs, landing pages | **RTC Agent Docs** |
| npm / pnpm | Svelte | Floating | SPA, lightweight integration | Mermaid Live Editor |
| npm | React / Vue / any framework | **Embedded** | Complex business app, multi-module | Peep |

## Common Integration Steps

Regardless of pattern, the core flow is always three steps:

1. **Expose host API on `window`** — so Agent can read/write your business state
2. **Declare Agent identity and tools** — describe persona and functions via `agentConfig`
3. **Mount the `<rtc-agent>` component** — configure `app-label` / `scenarios-url` / `server-url`

Full tutorial at [Getting Started →](/docs/en/getting-started/)
